description: 🧰 Compiling Hamspot.
---

### Requirements

- [Go](https://golang.org/dl/)

Clone repo and download dependencies:

```bash
cd $HOME
mkdir hamspot
cd hamspot
git clone https://github.com/spicetify/cli
```

### Build

#### Windows

```powershell
cd $HOME\hamspot\cli
go build -o hamspot.exe
```

#### Linux and MacOS

```bash
cd ~/hamspot/cli
go build -o hamspot
```
