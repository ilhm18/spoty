Making an extension from scratch can be a daunting task. Luckily, Hamspot provides a powerful API Wrapper that makes it easy to interact with Spotify's internal APIs as well as provide out-of-the-box methods to help you easily create extensions.

## Hamspot Object
You can access the Hamspot object by typing `Hamspot` in the DevTools console, inside your extension, or `window.top.Hamspot` if you're developing an app inside an `iframe`.

```ts
Hamspot
```

Navigate the sidebar to see all the methods and properties available in the Hamspot object!
